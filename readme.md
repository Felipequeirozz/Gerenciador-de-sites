# 🌐 Meus Sites Favoritos

Este projeto consiste no desenvolvimento de uma página web para organizar e acessar meus sites favoritos de forma prática e visual.

O site foi desenvolvido utilizando **HTML5 e CSS3**, como parte dos meus estudos em Desenvolvimento de Sistemas.

## 📌 Sobre o Projeto

A página foi dividida em duas seções:

- **Pessoal:** reúne meus sites favoritos para entretenimento, redes sociais e jogos.
- **Trabalho:** reúne ferramentas e plataformas utilizadas na minha rotina profissional.

## 🖥️ Tecnologias Utilizadas

- HTML5 — estruturação das páginas web.
- CSS3 — estilização, cores, layout e efeitos visuais.

## 📂 Estrutura do Projeto

```text
meus-favoritos/
│
├── index.html
├── trabalho.html
├── estilo.css
└── README.md
```

## 🎨 Funcionalidades

- Organização dos sites em páginas separadas.
- Navegação entre as seções pessoal e profissional.
- Imagens e links para acesso rápido aos sites.
- Layout estilizado com cartões, cores e efeitos de interação.
- Design adaptável para diferentes tamanhos de tela.

## 🚀 Como Executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em seu navegador.
4. Utilize o menu de navegação para acessar a página profissional.
